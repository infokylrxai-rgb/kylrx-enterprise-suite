Expected Excel Sheet Column Sequence

12 Columns · 3 Required · 9 Optional

Prepare your spreadsheet in this exact 12-column sequence. Columns 1–3 are mandatory; columns 4–12 will apply automatic zero-defaults if left blank.

COLUMN 01 Required *

Employee ID

Format: Unique Alphanumeric Code Example: EMP-1048
Aliases: empid, employeeid, id, empno
COLUMN 02 Required *

Employee Name

Format: Full Employee Name Example: Rahul Deshmukh
Aliases: empname, name, fullname
COLUMN 03 Required *

Salary (Base)

Format: Numeric Amount (INR) Example: 150000 or ₹1,50,000
Aliases: base, basic, basic salary, salary
COLUMN 04 Optional

Incentives

Format: Numeric (Default: 0) Example: 15000
Aliases: incentive, incentives
COLUMN 05 Optional

PF Contribution

Format: Numeric (Default: 0) Example: 1800
Aliases: pf, provident fund, pf contribution
COLUMN 06 Optional

ESIC

Format: Numeric (Default: 0) Example: 0
Aliases: esic, esi, esicontribution
COLUMN 07 Optional

Gratuity Provision

Format: Numeric (Default: 0) Example: 4500
Aliases: gratuity, gratuityprovision
COLUMN 08 Optional

ESOPs Grant

Format: Units / Text (Default: "None") Example: 100 Units or None
Aliases: esop, esops, equity
COLUMN 09 Optional

Variable Pay %

Format: Percentage (Default: 0) Example: 10% or 10
Aliases: variable, variablepay, variable %
COLUMN 10 Optional

Tax Deductions

Format: Numeric (Default: 0) Example: 12000
Aliases: tax, taxdeduction, tds
COLUMN 11 Optional

Bonus Structure

Format: Text (Default: "Standard") Example: Annual Performance
Aliases: bonus, bonusstructure
COLUMN 12 Optional

Shift Allowance

Format: Numeric (Default: 0) Example: 5000
Aliases: shift, shiftallowance
